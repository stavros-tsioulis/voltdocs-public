# MFRC522 v1.0 (MFRC52201HN1)

Original silicon revision of the MFRC522. Same pinout, package (HVQFN32),
electrical envelope, and host interfaces (SPI/I2C/UART) as later revisions.

Superseded by [version 2.0](../../index.md) (`MFRC52202HN1`), which improves
reader-IC stability under rough conditions, adds a timer prescaler, and fixes
CRC handling when `RxMultiple` is set.
